# CH.4 v2 — 촬영 화면 중심 UI 개편 + 프레임 저장 통일

기반: CH.4 DIGITAL/FILM v1.1 (기존 `filter_service.dart` 정수 타입 오류 수정본).

## 변경 사항

1. **촬영 화면 크게** — 상단 툴바를 48px 한 줄로 줄이고, 하단 필터 캐러셀을 상시 표시하지 않습니다. 필터 선택은 하단 시트로 이동했습니다. 실제 미리보기는 선택한 4:3/16:9/1:1 비율을 유지해 중앙에 최대한 크게 배치됩니다. 화면 비율 때문에 발생하는 여백은 의도된 것으로, 미리보기를 강제로 늘려 왜곡하지 않습니다.
2. **줌 우측 세로 배치** — 줌 배율 및 세부 슬라이더가 카메라 미리보기 오른쪽에 겹쳐 표시됩니다. 슬라이더를 열어도 미리보기 레이아웃이 변하지 않습니다.
3. **중복 조작 제거** — 앨범/렌즈 전환은 셔터 좌우에만 남기고, 추가 기능 패널에는 타이머·그리드·동영상 마이크·환경 설정을 배치했습니다. 화면비와 플래시(라이트)는 세로 화면 상단에 남겼습니다. 가로 화면에서는 폭에 맞춰 추가 기능 메뉴로 이동합니다.
4. **프레임 일원화** — `lib/widgets/frame_artwork.dart`의 하나의 프레임 페인터를 화면 오버레이와 내보내기 PNG 모두에 사용합니다. 필카는 퍼포레이션(필름 구멍), 35mm 엣지 마킹, 프레임 카운터를 적용합니다. 디카는 모서리 마킹, 색감 프로파일, 촬영 날짜/줌 표기를 적용합니다.
5. **저장 옵션 별도 제공** — 환경 설정의 `디카 화면 표시를 결과물에도 저장`, `필카 프레임을 결과물에도 저장`을 각각 ON/OFF 할 수 있습니다(둘 다 기본 ON). OFF여도 촬영 화면에서는 프레임을 보여줍니다. 두 개 저장할 때의 원본 파일에는 프레임/필터를 넣지 않습니다.
6. **사진과 동영상 결과물에 적용** — 사진은 이미지 처리 isolate에서 PNG 프레임을 합성하고, 영상은 FFmpeg의 이미지 합성 과정을 사용합니다. 저장할 때 4:3/16:9/1:1 크롭을 거칩니다. 처리 비용 때문에 영상 저장은 프레임이 활성화되면 재인코딩이 필요합니다.

## 적용

1. 기존 프로젝트를 Git에 커밋하여 백업합니다.
2. ZIP의 `lib/` 폴더와 `pubspec.yaml`을 현재 Flutter 프로젝트 루트에 복사합니다. **AndroidManifest.xml은 기존 정상 파일을 유지**하세요.

## 우선 확인해야 할 항목 (실기기)

- 사진/동영상 전환 후 상단바 및 미리보기 크기가 유지되는지
- 줌 레일을 열고 닫을 때 카메라 이미지가 밀리지 않는지 (세로/가로)
- 설정 패널이 카메라를 밀어내지 않고 겹쳐 뜨는지
- 디카/필카 촬영 JPG에서 프레임이 표시된 형태로 저장되는지
- 동영상 MP4에서 프레임 + 4:3/1:1/16:9 크롭이 반영되는지
- 원본 동시 저장 시 원본에는 프레임이 없는지
- 디카/필카 내보내기 프레임 옵션 각각 OFF일 때 저장본에서만 사라지는지
- 낮은 메모리/연속 촬영 시 저장 처리 및 촬영 반응성

## 기술적 제한/검증 상태

- **실제 Flutter SDK, Android 실기기가 제공되지 않아 `flutter analyze`, `flutter run` 실기기 테스트는 완료하지 못했습니다.** 현재 환경에서 Dart 파일 20개에 대해 문자열·주석을 제외한 괄호/중괄호/대괄호 구조 검사를 수행했습니다.
- FFmpeg 샘플 MP4/투명 PNG 합성 테스트는 16:9·4:3·1:1에서 성공했습니다. 다만 단말에 설치된 FFmpegKit 빌드 및 녹화 회전 메타데이터에 따라 결과가 달라질 수 있습니다.
- 프레임 디자인은 같은 페인터로 생성하지만 화면의 실제 필터 미리보기는 GPU 컬러 매트릭스 근사, JPG/MP4 필터 처리 방식은 별도이므로 **색감이 픽셀 단위로 동일하지는 않습니다**.
- 녹화 중 HUD에 기록되는 줌/촬영일/필름 프레임 번호는 **녹화 시작 시 값으로 고정**됩니다. 실제 줌 조작은 계속 가능합니다.
- 화면에 표시되는 `REC` 배지는 조작 상태 UI이며 결과물에 삽입되는 프레임 디자인에 포함되지 않습니다.
- 16:9 등 세로로 긴 비율은 촬영 정보/셔터 영역을 보존하는 현재 구조에서 미리보기 주변에 여백이 남을 수 있습니다. 비율을 무시한 화면 스트레칭은 하지 않습니다.

## 수정된 주요 파일

- `lib/screens/camera_screen.dart` — 화면 구성, 줌, 설정 패널, 필터 시트, 저장용 프레임 스냅샷
- `lib/widgets/frame_artwork.dart` — 실제 화면/내보내기에 공통으로 사용하는 프레임 디자인 **신규**
- `lib/widgets/camera_chrome.dart` — 버튼 디자인 컴팩트화, 구형 프레임 페인터 제거
- `lib/services/filter_service.dart` — JPG 프레임 PNG 합성
- `lib/services/video_filter_service.dart` — MP4 투명 PNG 합성
- `lib/models/camera_settings.dart`, `lib/services/settings_service.dart`, `lib/screens/settings_screen.dart` — 디카/필카 프레임 저장 옵션 분리
